# Stitched world scene studies

These images are visual direction studies for the forest and tidal worlds.
They are not aligned to level collision or parallax layers yet.
`home-menu-stage.png` is the full-resolution source for the Home background used in the game.

Both studies used the built-in image generator.
The tidal study used the forest study as a style and composition reference.

## Forest prompt

```text
Use case: illustration-story. Asset type: 2D side-scrolling game background concept for the stitched world of Palewheel. Create one wide landscape image with no characters or UI. A sunlit temperate forest sewn as a physical tabletop diorama: layered fabric hills, individually cut felt leaves, embroidered bark on tall trunks, hand-stitched moss, pressed-flower undergrowth, loose cotton tufts, visible threads, subtle paper and linen grain. A continuous open path runs horizontally through the middle third so a small platforming character could traverse the image; foreground foliage frames the bottom but does not cover the path. Warm cream daylight, sage and olive greens, russet bark, delicate soft shadows. Rich natural detail and strong depth through near/middle/far layers. Original game art, inviting and tactile, like a crafted set photographed straight-on with careful 2D composition. No text, symbols, HUD, buttons, people, characters, spikes, futuristic objects, dark fantasy, glossy plastic, or watermark.
```

## Tidal prompt

```text
Use case: illustration-story. Asset type: 2D side-scrolling game background concept. The supplied image is a style and composition reference only. Create a different stitched world: a bright tidal shoreline during low tide. Keep the same physical handmade diorama finish, straight-on 2D side view, warm linen and paper grain, fine embroidery, generous detailed near/middle/far layers, and a continuous traversable path through the middle third. New scene details: pale blue translucent quilted water in the distance, rippled cloth sand, hand-sewn sea grass, tiny shell appliques, driftwood with embroidered grain, stitched foam edges, dunes and grasses at the sides, soft morning sun. The path must be clearly dry and readable against the water. No character, text, UI, buttons, spikes, futuristic objects, castles, dark fantasy, glossy plastic, or watermark. Full opaque image with clean edges.
```

## Home menu prompt

```text
Use case: illustration-story. Asset type: full-screen home menu background for a 2D stitched-world platform game, landscape 16:9. The supplied image is a material and color reference only; create a substantially richer new composition. Build a tactile handmade diorama from woven linen, soft felt, embroidery, pressed flowers, cut paper, tiny visible stitches and seams. On the LEFT HALF, make a large, pale warm-ivory fabric pocket or sewn-on patch, organically shaped but broad and calm, occupying about 48% of the image from 8% to 92% height. Its center must be visually quiet and uniformly light enough for dark game title, short copy and four buttons to be drawn over it later. Give this patch a hand-sewn edge, small corner tacks and subtle fiber texture, but no printed marks. On the RIGHT HALF, show a detailed sunlit woodland clearing made from layered cloth hills, felt grasses, embroidered wildflowers, a few overhanging leafy branches and a small winding thread trail. Keep an open, quiet standing area centered around 72% width and 60% height where the game's dancer sprite will be placed; do not draw any character. Use cream daylight, sage, muted olive, warm rust and faded blue; natural depth, soft shadows, precise craft detail, welcoming and grounded. The finished artwork should feel like a real physical tabletop set photographed straight-on, with coherent proportions, no computer-perfect geometry. Full opaque image. No character, no lettering, no symbols, no buttons, no HUD, no logo, no frame around the whole image, no futuristic or fantasy elements, no watermark.
```
